📌 MÔ TẢ DỰ ÁN
--------------------------------------------------------------------------------
Dự án nghiên cứu và dự báo chất lượng không khí Thành phố Hồ Chí Minh năm 
2025 sử dụng Machine Learning và phân tích chuỗi thời gian.

Dữ liệu: 52,548 measurements từ 6 trạm quan trắc (23/02/2021 - 21/06/2022)
Các chỉ số: PM2.5, TSP, SO₂, NO₂, CO, O₃, Temperature, Humidity


================================================================================
                            HƯỚNG DẪN CÀI ĐẶT
================================================================================

BƯỚC 1: KIỂM TRA YÊU CẦU HỆ THỐNG
--------------------------------------------------------------------------------
Yêu cầu:
  • Python 3.8 trở lên
  • pip (Python package manager)
  • 2GB RAM trống
  • 500MB dung lượng ổ cứng

Kiểm tra Python version:
  $ python --version
  hoặc
  $ python3 --version


BƯỚC 2: TẢI PROJECT
--------------------------------------------------------------------------------
Clone repository (nếu có Git):
  $ git clone [repository-url]
  $ cd 2025-hcmut-khaiphadulieu-btl

Hoặc giải nén file zip đã tải về:
  $ unzip project.zip
  $ cd 2025-hcmut-khaiphadulieu-btl


BƯỚC 3: TẠO MÔI TRƯỜNG ẢO (VIRTUAL ENVIRONMENT)
--------------------------------------------------------------------------------
Tạo virtual environment:
  $ python -m venv myenv

Kích hoạt môi trường ảo:
  
  • Trên macOS/Linux:
    $ source myenv/bin/activate
  
  • Trên Windows:
    $ myenv\Scripts\activate

Lưu ý: Dấu nhắc terminal sẽ thay đổi thành (myenv) khi kích hoạt thành công


BƯỚC 4: CÀI ĐẶT THỨ VIỆN
--------------------------------------------------------------------------------
Cập nhật pip:
  $ pip install --upgrade pip

Cài đặt các thư viện cần thiết:
  $ pip install pandas numpy matplotlib seaborn scikit-learn scipy statsmodels

Hoặc sử dụng file requirements.txt (nếu có):
  $ pip install -r requirements.txt


BƯỚC 5: KIỂM TRA DỮ LIỆU
--------------------------------------------------------------------------------
Đảm bảo file dữ liệu có trong thư mục gốc:
  • HealthyAir_HCMC.csv (hoặc HealthyAir_HCMC_cleaned.csv)

Kiểm tra:
  $ ls -la *.csv


================================================================================
                            CÁCH CHẠY DỰ ÁN
================================================================================

CHẠY PHÂN TÍCH EDA (Exploratory Data Analysis)
--------------------------------------------------------------------------------
1. Kích hoạt virtual environment:
   $ source myenv/bin/activate    # macOS/Linux
   $ myenv\Scripts\activate       # Windows

2. Chạy file phân tích:
   $ python eda_target_creation.py

3. Chờ chương trình chạy (khoảng 1-2 phút)

4. Kiểm tra kết quả:
   - Terminal: Hiển thị thống kê và insights
   - File: eda_analysis.png (9 biểu đồ phân tích)
   - File: cleaned_data.csv (dữ liệu đã làm sạch)


CHẠY MÔ HÌNH MACHINE LEARNING
--------------------------------------------------------------------------------
1. Kích hoạt virtual environment (nếu chưa):
   $ source myenv/bin/activate

2. Chạy file mô hình:
   $ python ml_models.py

3. Xem kết quả dự đoán PM2.5


CHẠY DỰ BÁO 2025
--------------------------------------------------------------------------------
1. Kích hoạt virtual environment:
   $ source myenv/bin/activate

2. Chạy file dự báo:
   $ python forecast_2025_corrected.py

3. Kiểm tra file output:
   - forecast_2025.csv (dự báo PM2.5 cho 12 tháng năm 2025)


CHẠY DASHBOARD TỔNG HỢP
--------------------------------------------------------------------------------
1. Kích hoạt virtual environment:
   $ source myenv/bin/activate

2. Chạy dashboard:
   $ python dashboard_comprehensive.py

3. Xem 15 biểu đồ phân tích tổng hợp


TẮT MÔI TRƯỜNG ẢO
--------------------------------------------------------------------------------
Khi hoàn thành công việc:
  $ deactivate

================================================================================
                    KHẮC PHỤC SỰ CỐ (TROUBLESHOOTING)
================================================================================

LỖI: Python không được tìm thấy
--------------------------------------------------------------------------------
Giải pháp:
  • Cài Python từ: https://python.org
  • macOS: brew install python
  • Ubuntu: sudo apt install python3 python3-pip


LỖI: Pip không hoạt động
--------------------------------------------------------------------------------
Giải pháp:
  $ python -m ensurepip --upgrade
  
  Hoặc cài manual:
  $ curl https://bootstrap.pypa.io/get-pip.py -o get-pip.py
  $ python get-pip.py


LỖI: Import thư viện thất bại
--------------------------------------------------------------------------------
Giải pháp:
  1. Đảm bảo virtual environment được kích hoạt:
     $ source myenv/bin/activate
  
  2. Cài lại packages:
     $ pip install --force-reinstall pandas numpy matplotlib seaborn scikit-learn


LỖI: File dữ liệu không tìm thấy
--------------------------------------------------------------------------------
Giải pháp:
  1. Kiểm tra file có trong thư mục gốc:
     $ ls -la HealthyAir_HCMC*.csv
  
  2. Đảm bảo đang ở đúng thư mục project:
     $ pwd
     $ cd /path/to/2025-hcmut-khaiphadulieu-btl


LỖI: Biểu đồ không hiển thị
--------------------------------------------------------------------------------
Giải pháp:
  Cài backend cho matplotlib:
  $ pip install PyQt5
  
  Hoặc:
  $ pip install tkinter


LỖI: Virtual environment không kích hoạt được
--------------------------------------------------------------------------------
Giải pháp:
  • macOS/Linux: Kiểm tra quyền thực thi:
    $ chmod +x myenv/bin/activate
    $ source myenv/bin/activate
  
  • Windows: Cho phép chạy scripts:
    $ Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
    $ myenv\Scripts\activate
